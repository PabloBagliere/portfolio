Este es un artículo de ejemplo escrito en **Markdown**. Para publicarlo, cambiá
`draft: true` por `draft: false` en el frontmatter, o creá un archivo nuevo en
`src/content/blog/`.

## Podés usar todo Markdown

- Listas
- `código inline`
- [enlaces](https://astro.build)

```ts
// Y bloques de código con resaltado
const portfolio: string = 'hecho con Astro';
```

Los posts con `draft: true` no se publican en producción.
